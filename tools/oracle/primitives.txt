# The primitive set, and who is allowed to judge each one.
#
# Four tab-separated fields: id, status, judge, vectors.
#
#   id         the function prefix after gsec_. gsec_<id> and gsec_<id>_* match.
#   status     implemented, pending, or excluded.
#   judge      self, openssl, nist, rfc, wycheproof, or none.
#   vectors    a path pinned in tests/data/vectors/MANIFEST, or "-".
#
# implemented with an outside judge requires a vector file. pending may name
# one early — the corpus is allowed to land before the algorithm — and the
# file then has to exist and match the manifest. excluded means a declaration
# is a failed build: the design says this library does not grow that function.
#
# A new primitive is a new row, with a named caller in documentation/design.md,
# before the function is declared. tools/check_foundation.py is what enforces
# that. It is run on a planted gsec_ecdh_p256 first, and fails if that
# plant is not reported while ecdh_p256 is still pending.
